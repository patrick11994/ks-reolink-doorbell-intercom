Loading the texts…

Translate each text in the box next to it. The grey line under a text says where it appears. Your work is saved in this browser as you type, so you can stop and come back later.

Send it in

  1. Press Copy and open issue. Your translation is copied, and GitHub's form for translations opens in a new tab, with the language already filled in.
  2. Click in the box The file and paste with Ctrl+V.
  3. Press Submit new issue. That's it: the translation comes in the next release.

Sending an issue needs a free GitHub account. Rather attach a file? saves it as a .txt file you can attach to the issue instead.
